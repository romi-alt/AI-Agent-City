# Sales City – spec (from uploaded docs + screenshots)

## Visual reference (screenshots of office.fastsalestrainingcenter.com)
- 3D low-poly city, colourful mid-rise buildings, trees, streets; day and night (lit windows) modes.
- Views: **Office** (inside one floor: desks, labelled agents e.g. "VERA closer", "NICO follow-up"), **City** (orbit over the city), **Dashboard**.
- Left: view menu (View office, City view, Boss's desk, Content wall, Live screen, My CRM), floor picker (L7/L6/L5 available, L4 your office).
- Legend: Human / AI agent / Working / Needs you. Camera pad bottom-right (zoom, rotate, pan).
- Right panel tabs: LIVE, CRM, CONTENT, TEAM, OK, FLOORS. LIVE = KPI tiles (leads today, booked calls, enrolled, revenue, appointments, waiting >1h),
  "Open my CRM", enrollment pipeline bars, "What's happening in your office" activity feed.
- Top bar: logo, Office/City/Dashboard switch, ON DUTY, clock, user, theme toggle, lock, sign out.
- Sign-in: dark card, 6-digit authenticator code (2FA), remember device 30 days, recovery codes.
